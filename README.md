# Nimbus Chat ☁️

A real-time chat website built with Flask and Socket.IO. It has group chats, private messages, profile photos, photo sharing, and emoji, and it works on phones and desktops.

**Run it:**
`pip install flask flask-socketio` then `python app.py` and open `http://127.0.0.1:5000`

Messages and photos are kept in memory, so they reset when the server restarts.
